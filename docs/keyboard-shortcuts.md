# Keyboard shortcuts

Every key UDM's window answers. Everything the mouse does in the window
can be done from the keyboard too. While a key moves the focus, a ring shows
which control has it; pressing the mouse hides the ring until the keyboard
moves the focus again.

On macOS, `Ctrl` in this page is the Command key (⌘) for `Ctrl+A`, `Ctrl+F`
and the zoom keys.

## Anywhere

| Keys | What they do |
|---|---|
| `Tab` / `Shift+Tab` | Move to the next or previous control: the menus (on macOS and Linux), the toolbar, the categories, the column headers, the download list, and each dialog's fields and buttons. |
| `Space` or `Enter` | Press the button that has the focus, or tick the box. |
| `Up` / `Down` / `Left` / `Right` | Move to the control above, below or beside the one with the focus, in menus and dialogs. |
| `Escape` | Close the dialog you are in, a menu, or the find bar; elsewhere, take the focus off the control that has it. |
| `F10` | Go to the menu bar. On Windows the menu bar is Windows' own, so `Alt` does too, and `Alt` with an underlined letter opens that menu. |
| `Ctrl+Plus` / `Ctrl+Minus` / `Ctrl+0` | Zoom the window in, out, or back to 100%, for a while: the **Interface size** option takes over again when it or the theme changes (see [Themes and interface size](themes.md#interface-size)). |

In a text box the usual editing keys work: `Ctrl+C`, `Ctrl+X`, `Ctrl+V`,
`Ctrl+Z`, `Ctrl+A`, `Home` and `End`.

## The download list

These work while a row of the list has the focus (`Tab` to it, or click a
row), or while no control has it.

| Keys | What they do |
|---|---|
| `Up` / `Down` | Select the download above or below. |
| `Page Up` / `Page Down` | Select the download a screenful up or down. |
| `Home` / `End` | Select the first or the last download. |
| `Shift+Up`, `Shift+Down`, `Shift+Page Up`, `Shift+Page Down`, `Shift+Home`, `Shift+End` | Select every download from the one selected last to the one the key moves to. |
| `Ctrl+Up`, `Ctrl+Down`, `Ctrl+Page Up`, `Ctrl+Page Down`, `Ctrl+Home`, `Ctrl+End` | Move the focus without changing what is selected. |
| `Space` | Select the download with the focus. `Ctrl+Space` adds it to the selection or takes it out; `Shift+Space` selects every download from the one selected last to it. |
| `Ctrl+A` | Select every download the list shows. |
| `Enter` | With one download selected: open it if it is finished, else show its download window. |
| `Delete` | Remove the selected downloads that are not running, as **File > Remove** does. |
| `Shift+F10` | Open the menu of the download with the focus, the one a right-click opens. `Escape` closes it. |

`Space` or `Enter` on a column header sorts the list by it, as a click does;
**View > Arrange files** sorts it too, and **View > Customize URL List** picks
the columns, which a header's right-click menu also opens.

A screen reader reads each row as its name, status, progress (the share done
and the size) and speed, then the time left while it downloads and why it
failed when it did.

## Finding a download

| Keys | What they do |
|---|---|
| `Ctrl+F` | Open the find bar above the list, with the focus in its box. |
| `F3` | Open the find bar, or go to the next match while it is open. |
| `Shift+F3` | Go to the previous match. |
| `Enter` | In the find box: go to the next match (`Shift+Enter`: the previous one). |
| `Escape` | Close the find bar and show every download again. |

## The categories

| Keys | What they do |
|---|---|
| `Up` / `Down` | Move to the category above or below. |
| `Right` / `Left` | Open or close the branch with the focus (All Downloads, Unfinished, Finished, Grabber projects, Queues). |
| `Space` or `Enter` | Show the category with the focus in the list. |

## Dialogs

| Keys | What they do |
|---|---|
| `Enter` | In the address box of **Add URL**, a new queue's name in the save-as dialog, a link being edited in the link list, or the password box of a login: the same as the button beside it (OK or Add). |
| `Escape` | Close a dialog that has a close button, like Cancel. |

The tray icon's menu and, on Windows, the menu bar are the system's own, and
answer its keys (the arrow keys, `Enter`, `Escape` and the underlined
letters).
