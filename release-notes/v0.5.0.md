**Release type:** minor

Pullbay is now called **UDM** (Unified Download Manager), with a new icon, and its window is new: drawn with Tauri in your system's webview, laid out like IDM's and styled like Windows 11. This release also adds a command-line tool, an MCP server for AI assistants, control from a phone, a server mode with a Docker image, video sites through yt-dlp, image galleries, packages with unpacking, FTPS and 13 more languages.

## Breaking changes

- Pullbay is now UDM: its programs, folders, menu entries and browser connection have new names. Install UDM over Pullbay or UIDM. The first time a UDM program starts, it moves over the old settings, download list, logs, browser registrations and start-at-sign-in entry. Half-finished downloads resume, and site passwords saved in Pullbay still work. Pullbay's Update now can install it.
- Load the browser extension again, because Pullbay's went with its folder. Remove the Pullbay extension, then load UDM's as the [install guide](https://github.com/tajbinkhan/UDM/blob/main/docs/install.md#coming-from-pullbay-or-uidm) describes. In Chrome and Edge it keeps the same ID; in Firefox it is a new add-on, `udm@udm.local`.
- On Windows, Setup closes Pullbay, installs into a `UDM` folder beside Pullbay's and removes Pullbay's folder and shortcuts. It also installs the WebView2 runtime when Windows lacks it. The `udm` deb and rpm packages replace `pullbay` and now need WebKitGTK 4.1, and `install.sh` removes Pullbay's copy in `~/.local`. On macOS and with the AppImage, delete `Pullbay.app` or the Pullbay AppImage yourself.

## New

- A new window, drawn with Tauri. It has every window IDM's has but Registration, plus UDM's own: the browser's link, video and gallery pickers, packages, the update check, Options' extra pages, problem reports, the clipboard monitor, the zip preview, Convert, Verify checksum and Open with. (55d4705, 4d2b606, 9c79c88)
- The window looks like Windows 11: Mica grays and the default accent in the Light and Dark looks, rounded controls and menus, filled default buttons and checked boxes, and icons from Microsoft's Fluent UI System Icons (MIT). The download list's rows are taller, and an empty list says where new downloads appear.
- Themes, a high-contrast look and an interface size up to 200%, plus theme files of your own. (fe0f777)
- `udm-cli`, a command-line tool for terminals and scripts, with a documented automation API. (ee59f52)
- `udm-mcp`, a Model Context Protocol server, so AI assistants can list, add, pause and resume downloads. (02a770f)
- Control UDM from a phone on the home network: pair it with a QR code and manage downloads from its browser. (042c82c)
- Run the background service on a server with `udm-daemon --server`, or in the Docker image. (9f770d8)
- Download from any site yt-dlp reads, including playlists and sound only. UDM installs and updates yt-dlp and ffmpeg for you. (9ca2874)
- Download image galleries with gallery-dl. (8dba986)
- Keep links as packages, and unpack their archives when they finish, including split archives. (cd8bcf6)
- Download from FTPS servers. (f3d55dc)
- Verify a download's checksum. (e8ea0a7)
- Lift the speed limit while nobody uses the computer. (0b6e2cd)
- A portable copy keeps its files in its own folder. (aa89226)
- Crash and freeze reports, and Report a problem fills in the issue for you. (b3cd57f)
- The window reads to screen readers, and every key it answers is listed in the docs. (38dd811)
- The window and the extension in 13 more languages. Some of the new window's text is still English in other languages. (7975ab0, e204562)

## Changed

- The download engine copes better with servers that drop connections, limit clients, start slowly, send wrong ranges or throttle. (7006e77)
- The first download after the background service has stopped starts about two seconds sooner on Windows. (83347ca)
- The toolbar's buttons are as wide as their names, so Delete Completed shows whole, and Options > Sounds shows each event's full name.

## Fixed

- The background service could quit less than a minute after a short command or download that came and went within five seconds. It now counts every client. (83347ca)
- Removing a video page's download with its files left yt-dlp's half-fetched parts beside the video. They now go to the Recycle Bin too.
- The domain's and the background service's errors show in your language again. (9c79c88)
- On Windows, Download File Info put a backslash before the file name in a folder written with slashes. It now uses the folder's own separator. (93c5f45)
- `udm-cli` made the background service log a read error each time it closed its connection. It no longer does.
