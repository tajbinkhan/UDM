**Release type:** minor

UDM now downloads torrents and magnet links, can send every download through one network adapter such as a VPN's, and starts fetching a file while Download File Info is open, as IDM does. This release also adds debrid accounts for file-host links, a Safari extension, four more languages with right-to-left windows, and updates that install only signed files.

## New

- Download torrents and magnet links. Add them with Add URL, the clipboard, the browser (magnet links you click and `.torrent` files it downloads), **Tasks > Open torrent file...** or `udm-cli get`. Download File Info lists a torrent's files to tick, and its download window shows files, peers, trackers, pieces and seeding limits. A finished torrent seeds until a share ratio of 1.0 or an hour, set in **Options > Torrents**. ([Torrents and magnet links](https://github.com/tajbinkhan/UDM/blob/main/docs/torrents.md), #249, 7bb464a, ef56442)
- Send every download through one network adapter, such as a VPN's, in **Options > Network**. When that adapter is down, nothing connects, so no download goes out another way. On Windows, torrents do not run while an adapter is chosen. (#261, 2080ed6, 2f44624)
- Look up host names with DNS over HTTPS at Cloudflare, Google, Quad9 or a server you name. (#261, 2080ed6)
- A **Country** column and the download window show the server's country, from an address table built into UDM, so nothing is looked up online. (#261, 2080ed6)
- Download file-host links such as Rapidgator and 1fichier through a Real-Debrid, AllDebrid or Premiumize account, an experimental option in **Options > Debrid**. (#259, 0f76a78)
- The browser extension in Safari on macOS, carried by UDM.app. It was built for Safari but not yet run in it. (#268, 8cd3038)
- The extension is ready for the Chrome Web Store and Firefox Add-ons, and each release carries the zips the stores take. Until the listings are up, load the extension by hand. (#248, a8adf11)
- Hebrew, Arabic, Persian and Hindi, 21 languages in all. Hebrew, Arabic and Persian lay the windows out right to left. The first start asks which language to use, and **View > Language** changes it. The new translations wait for a native speaker's review. (#251, a20aea2)
- Screenshots and five step-by-step guides in the help pages. (#269, f67b31c)

## Changed

- **Start downloading while the save-as dialog is open** is on by default, so a file the server sends in ranges comes in while you choose where to save it. If your settings already have it off, it stays off. A torrent never starts early. (72ca5a0)
- Update installs only files the release's signed checksum list names, and refuses an update without UDM's signature. It now also updates in place on macOS and Linux: UDM.app, the AppImage, or a `.tar.gz` copy installed with `install.sh`. A `.deb` or `.rpm` copy says to update through the package manager. (#267, 9b87224)
- A manual SOCKS5 proxy is handed to yt-dlp and gallery-dl as `socks5h`, so they leave name lookups to it too. (2080ed6)

## Fixed

- A menu taller than the window, such as **View > Language** in a small window, ran past its edges. It now stops at them and scrolls. (4a791a5)
- On Linux, the download window drew **Resume capability** in a wide font that pushed the address out of view. It no longer does. (f67b31c)
