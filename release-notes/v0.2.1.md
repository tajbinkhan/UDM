**Release type:** patch

This release fixes a browser extension error from 0.2.0.

## Fixed

- On pages with many frames, such as Gmail, Chrome's extension page showed "Uncaught SyntaxError: Identifier 'MIME_EXTENSIONS' has already been declared". A frame could get UIDM's page scripts twice, from the browser and from UIDM adding them to tabs that were already open, and the second copy failed. A second copy now does nothing, and UIDM adds the scripts to an open tab only once. (#167, 0783d4d)
