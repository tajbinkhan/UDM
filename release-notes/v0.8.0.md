**Release type:** minor

**Update now** now updates UDM installed from the `.deb` or `.rpm`, through your system's package manager.

## New

- If you installed UDM from the `.deb` or `.rpm`, **Update now** downloads the new package, checks it against the release's signed checksums, and installs it with your package manager (apt or dpkg for a `.deb`; dnf, zypper or rpm for an `.rpm`). Your system asks for your password first. UDM then closes and starts the new version. Your package manager still owns UDM's files, so you can remove it as usual. If you close the password prompt, nothing is installed and About says so. (fcb9e36)

## Changed

- About no longer tells `.deb` and `.rpm` copies to update through the package manager, which never found a new version because UDM is in no package repository. It now says that only for a package UDM can't update itself, or when a release has no package for your processor. (fcb9e36)

## Updating to this version

If you installed UDM from the `.deb` or `.rpm`, install this version by hand once. Your current copy doesn't have the new update code yet. From the folder where you downloaded the file:

- `.deb`: `sudo apt install ./udm_0.8.0_amd64.deb`
- `.rpm`: `sudo dnf install ./udm-0.8.0-1.x86_64.rpm`

From then on, **Update now** does it for you. Other installs update with **Update now** as before.
