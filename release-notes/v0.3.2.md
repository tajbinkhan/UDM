**Release type:** patch

This release makes UIDM's window behave on Linux as it does in IDM: closing it leaves UIDM in the tray, and its icon shows in the dock.

## Fixed

- On Linux, closing the window with "Closing the window keeps UIDM in the tray" on only minimized it, so it stayed in the dock. The window closes now and UIDM keeps running in the tray: the tray's Open UIDM, starting UIDM again, or a download that needs its save-as dialog brings it back, and Pause all, Resume all and Speed limit work from the tray while it is closed. (42254ca)
- On Linux, the dock, the taskbar and the window switcher showed a generic icon for UIDM's windows. They show UIDM's icon now. (42254ca)
