**Release type:** minor

UDM now installs only from its own files, so Scoop and winget are gone, and windows on macOS get their full height back.

## Breaking changes

- UDM no longer comes from Scoop. If you installed 0.13.0 with Scoop, `scoop update udm` fails from this release on, and **Update now** runs Setup, which installs a second copy beside the Scoop one. Run `scoop uninstall udm`, then install UDM with Setup from the list below. (#343, 60dc4df)

## Changed

- The `winget install` steps are gone from the install guide. 0.13.0's notes listed them, but the package was never accepted into winget, so the command never found UDM. (#341, 0309158)
- Setup no longer offers to install the video tools with winget. If yt-dlp is missing, Setup's last page points you to **Options > Tools**, which installs it. (#343, 60dc4df)

## Fixed

- On macOS, every window was a title bar shorter than on Windows and Linux, so Add URL cut off its authorization box and Options had to scroll. Now each window shows its whole page. (#345, b0255c3)
- A download added by hand sent no User-Agent unless one was set in Options, and some servers refused it with "403 Forbidden". Now it sends UDM's own, and a User-Agent from the browser or Options still takes its place. (#345, b0255c3)

## Install

Pick the file for your system from the list below. The [README](https://github.com/tajbinkhan/UDM#download) has the full steps.

The files are not code-signed yet, so Windows SmartScreen may say "Windows protected your PC" the first time. Click **More info**, then **Run anyway**. The [code signing policy](https://github.com/tajbinkhan/UDM#code-signing-policy) says how release files are built and who approves them.

The macOS disk image is experimental. It builds and passes CI on macOS, but it has not been run on a real Mac yet, so please [open an issue](https://github.com/tajbinkhan/UDM/issues) for anything that goes wrong.
