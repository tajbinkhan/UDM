**Release type:** minor

UIDM is now called **Pullbay**, with a new icon. Your settings, download list and half-finished downloads come with you. This release also shows the background service's errors in your language, and downloads videos from sites that check the player's headers.

## Breaking changes

- UIDM is now Pullbay: its programs, folders, menu entries and browser connection have new names. The first time Pullbay starts, it moves over UIDM's settings, download list and logs, its browser registrations and its start-at-sign-in entry, and half-finished downloads resume where they stopped.
- UIDM 0.3.3 cannot install this update by itself. It tells you a new version is out and opens this page: download the file for your system below and install it over UIDM.
- Load the browser extension again, because UIDM's went with its folder. Remove the UIDM extension, then load Pullbay's as the [README](https://github.com/tajbinkhan/pullbay#install) describes. In Chrome and Edge it keeps the same ID; in Firefox it is a new add-on, `pullbay@pullbay.local`.
- On Windows, Setup closes UIDM, installs into a `Pullbay` folder beside UIDM's and removes UIDM's folder and shortcuts. The `pullbay` deb and rpm packages replace `uidm`, and `install.sh` removes UIDM's copy in `~/.local`. On macOS and with the AppImage, delete `UIDM.app` or the UIDM AppImage yourself.

## Changed

- A new icon: a white arrow on orange, in the window, the tray, the installers and the browser extension. (d0ccf49)
- Errors from the background service, such as a refused address, a setting it would not take, or a new link that does not fit a half-finished download, now appear in the window's language (German, Spanish or French) instead of English. (#234, d71a6f2, 0fbcb75)

## Fixed

- Some sites refuse a video stream unless the request carries the headers their player sent, such as Origin, Referer or a token, so Pullbay could not download those videos. The extension now passes those headers along. (adcd652)
- The save-as dialog asked a video's web page or a stream's playlist about the file, as if it were the file itself. It no longer does. (adcd652)
- When the download engine's network runtime failed to start, the background service could close. Now only that download fails, and the next one tries again. A few other rare failures also fail the one action instead of closing the program. (bbbc445, cce067b)
