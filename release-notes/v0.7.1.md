**Release type:** patch

UDM can now open the browser extension's folder for you, so loading the extension by hand takes one click on every system.

## New

- **Options > Browser capture** has **Open extension folder**, for **Load unpacked** in Chrome, Edge, Brave and other Chromium browsers, and **Open Firefox extension folder**, for Firefox's `about:debugging` page. Before this, only the last page of Windows Setup opened the folder. If UDM cannot find the folder, the page says so. (e5d6870)

## Install

Pick the file for your system from the list below. The [README](https://github.com/tajbinkhan/UDM#install) has the full steps.
