**Release type:** minor

You can install UDM with winget or Scoop, a video's qualities show sooner when you click **Download this video**, and the menus and toolbar are translated in every language.

## New

- Install UDM on Windows with `winget install` or from Scoop. A Scoop copy leaves its updates to Scoop, instead of running Setup and installing a second copy beside it. (#336, 6fecd05)

## Changed

- The video button's quality list opens sooner. UDM starts reading the video when the pointer reaches the button, reads a video and its playlist at the same time, and remembers each page's qualities for an hour. (#338, adb3a97)
- UDM now installs yt-dlp's folder build, which starts in about a third of the time the one-file program took. A yt-dlp that an older UDM installed is replaced at the next daily update check, or at once when you click **Install**. (#338, adb3a97)

## Fixed

- Labels kept in the code, such as many menu items and toolbar buttons, showed in English in every language. Now they show in the language you picked. (#337, f3cc18b)

## Install

Pick the file for your system from the list below. The [README](https://github.com/tajbinkhan/UDM#download) has the full steps.

The files are not code-signed yet, so Windows SmartScreen may say "Windows protected your PC" the first time. Click **More info**, then **Run anyway**. The [code signing policy](https://github.com/tajbinkhan/UDM#code-signing-policy) says how release files are built and who approves them.

The macOS disk image is experimental. It builds and passes CI on macOS, but it has not been run on a real Mac yet, so please [open an issue](https://github.com/tajbinkhan/UDM/issues) for anything that goes wrong.
