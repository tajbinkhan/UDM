**Release type:** patch

A download caught from the browser opens its dialog alone and in front, the dock shows UDM's icon on Linux, and right-click menus and two small windows no longer cut anything off.

## Changed

- Releases no longer carry a `Pullbay-Setup` copy of Windows Setup. Pullbay 0.4's **Update now** looked only for that name, so a Pullbay copy now finds no new version: download `UDM-Setup-<version>.exe` and run it yourself, and it moves Pullbay's settings and downloads over as before. (56d44da)

## Fixed

- When UDM was not running, a download caught from the browser opened the main window as well as **Download File Info**, and on Linux the dialog could open behind the main window. Now the dialog opens alone, with UDM in the tray, and on Linux a dialog opened while the main window is showing stays in front of it. (956a587)
- On Linux, the dock showed a blank gear named **udm-gui** for UDM's window instead of UDM's icon. It now shows UDM's icon and name. (956a587)
- A right-click menu tall enough to reach the menu bar showed the menu bar's names, such as **Help**, on top of its own items. The menu now covers the bar, and when it is taller than the window its rows sit closer together so more of it fits. (956a587)
- The top of the address in a download's window could be cut off, and the buttons of **Confirm deletion of downloads** could fall below the window's edge. Both now show in full. (39809cd)
