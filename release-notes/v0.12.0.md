**Release type:** minor

UDM can now update from its own download server, and a crafted FTP address can no longer send your saved login to the wrong server. Please update.

## New

- **Check for Update** and **Update now** try UDM's own update server first, so a network that GitHub turns away can still update. If that server is down, is missing a file, or a file fails its signature check, UDM uses GitHub. Every update is still checked against UDM's signed checksums before it installs. (#331, fabfa74)

## Fixed

- A crafted `ftp://` address with a backslash in it could connect to one server while UDM chose the login you saved for another, which sent that login to the wrong server. Now UDM chooses a saved login by the server the download actually connects to.
