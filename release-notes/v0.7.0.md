**Release type:** minor

UDM now offers to install yt-dlp, ffmpeg and gallery-dl when they are missing, and downloads a new version ahead so installing it takes one click. It also stops offering the version you already have after an upgrade.

## New

- At the first start, UDM lists the tools it did not find (yt-dlp, ffmpeg, gallery-dl), says what each is for, and installs the ones you tick. While one is missing, a strip on the main window names it, with **Install them**, **Show** and a close button. Closing the strip hides it until another tool goes missing. Where UDM cannot install a tool, it shows the package manager's command. (dab420b)
- When the weekly check finds a new version, UDM downloads it and checks it against the release's signed checksums. The main window and About then say it is ready, and **Update now** installs it without downloading it again. Nothing installs until you click. Turn it off in **Options > General**. A `.deb` or `.rpm` copy still updates through the package manager. (dab420b)

## Fixed

- After installing a new version over a running UDM, the background service kept running the old version and offered the new one as an update, and Options could show tools as missing or stuck on **Installing...**. The window now restarts a background service older than itself, and offers only versions newer than itself. The service saves the download list before it stops. (dab420b)
