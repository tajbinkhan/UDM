**Release type:** minor

Installing yt-dlp, ffmpeg or gallery-dl shows how far the download is, and the download window lines its values up in one column.

## New

- Installing yt-dlp, ffmpeg or gallery-dl from the Tools sheet, the main window's strip or **Options > Tools** shows a bar and how much has arrived, such as **12.0 MB of 40.0 MB (30%)**, then **Checking and installing...** once the whole file is in. Before, it showed only **Installing...** for as long as the download took, which looked stuck on a slow server. When the server gives no size, it shows the bytes alone. (a00e527)

## Changed

- The download window shows every value in one column, and sizes and speed with two decimals, as the list and Download File Info do: **30.78 MB (4.45%)** and **9.05 MB/s** instead of **30.777 MB ( 4.45 % )** and **9.053 MB/s**. **Resume capability** no longer sits off to the side. (a00e527)

## Fixed

- If the background service stopped while a tool was installing, its button could show **Installing...** until you restarted UDM. The window now forgets the install when it loses the service. (a00e527)
