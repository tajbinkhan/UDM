**Release type:** patch

A finished download opens the **Download complete** dialog by default, as IDM does.

## Changed

- **Show download complete dialog** (Options → Downloads) is now on by default, so a finished download opens the **Download complete** dialog instead of a notification. When no window is open, a notification still stands in for it. A copy that has already saved its settings keeps the choice it had: turn the box on in Options → Downloads to get the dialog. (#320)
