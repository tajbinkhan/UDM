**Release type:** patch

**Check for Update** no longer fails with "server returned HTTP 403" on a busy or shared network.

## Fixed

- **Check for Update** and the weekly check could fail with "Could not reach GitHub: server returned HTTP 403". UDM asked GitHub's API, which answers a network only 60 times an hour, and other programs or people on the same address used that up. Now UDM reads the release from GitHub's website, which has no such limit. (#329, b6b5a8d)
- When GitHub does turn a network away, the About window said UDM could not reach it. Now it says GitHub is turning away requests from this network for now, and to try again later. (#329, b6b5a8d)
