**Release type:** minor

This release moves UIDM's tray and dialogs closer to IDM's and adds the network and power features found in a pass over IDMan.exe: HTTP/2, NTLM logins, subtitles from streams, and keeping the computer awake for downloads and schedules.

## New

### Downloads and the network
- Downloads use HTTP/2 when the server offers it, and the parts of one download share a single connection. (#179, 963ce0b)
- Servers that ask for an NTLM or Negotiate login get one from the matching site login. Use "DOMAIN\user" to give the domain. The password never goes to the server. (#180, d6ededa)
- HLS and DASH streams keep their WebVTT subtitles. The video button's menu lists them with a checkbox each. With FFmpeg they go into the video, and without it each is saved beside the video as a .vtt file. (#183, 8093e98)
- A download into a folder that needs administrator rights, such as one under C:\Program Files, opens the save-as dialog with "Save there with administrator rights". The download runs as you and Windows asks for permission once, to move the finished file. (#162, fa69e57)
- Other programs can send links to UIDM with `uidm-host send`, which reads JSON with the address, referrer, cookies, POST data and login. The README has PowerShell and Python examples. (#160, 4cdafd4)

### Power
- The computer stays awake while a download, site grab or conversion runs. The display can still turn off. Options > General has the setting, on by default. (#182, 4e75d2e)
- Queue and grabber schedules can wake the computer to start, on by default. A schedule warns when the power plan has wake timers turned off. (#181, 3c717fc)

### The window and the tray
- Minimizing the main window hides it in the tray, as in IDM. Options > General can turn this off. (cc8e3dd)
- The download window opens when a download starts. Its Hide button puts it in the tray behind a second icon, whose menu lists the hidden windows and brings one back. (a75e6e3, 8b0341e)
- Drag a finished file out of the Download complete dialog or the download list into another program, such as a player's playlist. Windows only. (#161, 0b474cd)
- The video button over a playing video is a bar like IDM's, with "?" for help and "x" to close it for that player. (55a0a0b)
- New settings start with IDM's list of addresses never captured, such as site sounds and update files. Existing settings get the list once, after your own addresses. (#163, ed394f6)
- Setup offers to install yt-dlp, FFmpeg and Deno through winget when yt-dlp is missing. (3bd966d)

## Fixed

- A save-as dialog for a download caught from the browser opened behind the browser. It comes to the front now. (fae2811)
- With UIDM in the tray, a caught download's save-as dialog or download window could not open. Both open now, without bringing the main window up. (a75e6e3)
- A click on the main window covered any open dialog. Dialogs now stay in front of it. (32922af)
- With the main window in the tray, a save-as dialog opened near the top-left corner of the screen. Dialogs now open in the middle of the screen under the mouse. (d801786)
